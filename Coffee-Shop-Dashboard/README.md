# ☕ Coffee Shop Sales Dashboard

## Overview

This project is an interactive Microsoft Excel dashboard built to analyze coffee shop sales data. The dashboard transforms raw transaction data into meaningful business insights using data cleaning, PivotTables, PivotCharts, and interactive slicers.

The goal of the project is to help business owners and managers monitor sales performance, identify trends, and make data-driven decisions.

---

## Project Objectives

- Clean and prepare raw sales data for analysis
- Calculate revenue for each transaction
- Analyze overall sales performance
- Identify best-selling products
- Explore revenue trends over time
- Build an interactive dashboard for business reporting

---

## Dashboard Features

The dashboard includes interactive visualizations and key performance indicators (KPIs) that allow users to explore sales data quickly.

Examples include:

- Total Revenue
- Total Transactions
- Sales Trends
- Product Performance
- Interactive Slicers for filtering data
